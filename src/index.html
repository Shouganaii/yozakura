Redirect & encoding

Straight to the destination puts the URL inside the code itself — the most reliable choice, though reprinting is the only way to change where it leads. Through this page encodes a link back to the link base above, carrying the destination with it, so whoever scans gets the animation before they arrive. Set the link base to the host you will actually deploy to — or to a short link you control, if you want to be able to re-point a code that is already printed.

Or press and hold the image (right-click on desktop) to save it.
